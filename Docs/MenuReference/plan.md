# Reference menu UI

Charcoal #16181D, panel #292C31, teal #219C94, white #F2F5F7. Bundled Barlow Black/Bold (SIL Open Font License) keeps headings consistent in browser builds and works offline.

Home: 40% left panel with title, subtitle, teal Play and gray How to Play; 60% scene artwork. Selection: title, Back, four image cards (all current stages), teal selected border and separate Play Level action. Narrow windows use two columns. Preserve campaign unlock rules and tutorial routing.

Artwork is rendered from the actual authored stages with an inspection camera, not the supplied mockup's embedded labels. Existing scene buttons retain their persistent bindings. Card clicks select; explicit Play launches.
