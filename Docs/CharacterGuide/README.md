# Character guide

Main menu → Characters opens one image-led page covering Guard, Heavy and Engineer. Portraits are rendered from the actual CharacterAvatarView models, including their current uniforms and tools. Each role has one purpose and one control hint. Back or Escape returns to the main menu.

Recreate portraits and screenshot using Possession.Editor.MenuReferenceBuild.CaptureRolePortraits. Runtime loads static textures, with no extra cameras or models.
